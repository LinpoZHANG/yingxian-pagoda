# 应县木塔 · Web3D 程序化生成

> 佛宫寺释迦塔(1056,辽清宁二年)—— 基于 Three.js 的纯程序化
> 建模场景。无 GLB / 无 Blender / 无外部模型与贴图资产,
> 全部几何与纹理由代码生成。

## 运行

```bash
npm install
npm run dev        # 开发,默认 http://localhost:5173
npm run build      # 构建到 dist/,可任意静态目录部署
```

## 架构约定(填写代码时务必遵守)

1. **参数唯一**:任何构件文件不允许出现魔法数字,尺寸一律来自
   `data/pagodaParams.js` / `data/caifen.js`,数值带来源标注
   `[测]/[图]/[法]/[估]`。
2. **单位 = 米**:场景 1 单位 = 1 米,塔总高 67.31。
3. **状态唯一**:所有交互经 `interaction/states.js`,禁止模块间
   直接互调改场景;切换必须缓动过渡。
4. **构件纯函数**:components 只产出 Group/Geometry,不感知场景、
   不挂事件;语义信息写入 `userData`(level / type / partKey)。
5. **性能纪律**:重复构件 InstancedMesh;斗拱按 config 缓存;
   纹理 ≤1024 全局复用。

## 交互

| 操作 | 说明 |
|---|---|
| 拖拽 / 滚轮 / 右键 | 旋转 / 缩放 / 平移(自由视角) |
| 点击构件 | 弹出构件信息卡(柱、斗拱、昂、枋、瓦、刹……) |
| `1`–`5` / `0` | 逐层导览 / 回到全景 |
| `空格` | 自动巡航开关(环塔螺旋上升) |
| `X` | 结构分解(九个结构层沿竖向拉开;分解态下再选层可单层聚焦) |
| `B` | 斗拱特写(英雄级一层外檐转角铺作,可分解) |
| `G` | 古今面貌(立面在夹泥墙与木构之间切换) |
| `N` | 昼夜切换 |
| `H` / `?` | 操作说明与资料来源 |

所有切换均由 `interaction/states.js` 统一调度并缓动过渡,无瞬切。

### 古今面貌

底部工具条的《古今面貌》点一次换一个年代,换的是立面上的两样东西 ——
**二至五层明层次间的墙**,与**全塔外露面的面层口径**:

| | 古貌(1933,拆墙前) | 今貌(1935 至今) |
|---|---|---|
| 次间 | 夹泥墙,木骨分格填泥抹灰 | 木版壁,板上刷红涂料(逐块板漆厚薄不一,红里透木) |
| 墙内斜撑 | 有(藏于墙内,过渡中显露) | 已随墙拆除,未复原 |
| 斜向四面当心间 | 封死 | 通间直棂窗 |
| 东西正向当心间 | 一扇小窗(宽 0.56 间、五棂) | 通间九棂窗 |
| 墙面位置 | 泥墙厚 0.435 m,外凸约 5 cm | 版壁厚 0.34 m |
| 栱眼壁 / 门窗余壁 / 门颊 | 暖白抹灰 | 木面 + 暗红油饰 |
| 首层墙 | 砖 / 抹灰土色 | 铁红油饰(实照取色) |
| 立面读感 | 红白相间,封闭厚重 | 通体木色,玲珑通透 |

「纯木结构」说的是承重体系,不是外立面全为裸木;反过来,今天的立面上也确实
**一处浅色抹灰都找不到**。两个年代之间主体结构无可考的形态变化,
故柱、阑额、铺作、屋面、平座、首层砖墙、台基与塔刹一律不动。
过渡是 2 秒的**历史结构解释动画**(抹灰退 → 斜撑短暂显露 → 版壁与格窗接手),
面层的颜色走一层渐变遮罩、不做跳变;动画顺序不声称真实维修按此发生。
**设计规范见 [`docs/facade-design.md`](docs/facade-design.md)** —— 材质分组、色系关系、
逐件色差、变化动画、调参判据,分门别类写全,是改这部分之前该读的那一份。
资料源与证据等级见 `reference/FacadeHistory/`;逐轮的来龙去脉见 `docs/adjustments.md`。
