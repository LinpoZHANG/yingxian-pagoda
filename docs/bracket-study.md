## 一、材分基准标定 ★已实证

**材广 25.5cm × 材厚 17cm,分° = 1.7cm** —— 双重证据:
1. 图版21(p93)"内槽转角铺作正面"高度尺寸链中 25.5 连续重复出现
   (逐层材栔叠加的直接读数);
2. 自洽验证:同图"外檐柱头铺作侧面"总出跳标注 209cm,
   七铺作 4 跳 → 209/4 ≈ 52cm/跳 = 30分 × 1.7cm ✓(《法式》每跳30分吻合)。
→ caifen.js:CAI_BASE = { guang: 0.255, hou: 0.17 },FEN = 0.017(米)。
出跳标注链 85 / 143 / 209(p93)供逐跳减跳规律精读时展开。

## 二、已实证的铺作形制

**一层外檐柱头铺作(图版21 p93)**:七铺作双抄双下昂——侧面图可清点:
两层华栱出跳后接两层下昂斜出,昂嘴批竹;耍头在令栱之上;
橑檐枋断面带标注(16×80/16×12 类椽枋记号待细读)。
→ assemble.js 主配置:{ tiao:4, ang:2, role:'zhutou', facing:'out' }。

**副阶铺作(图版20 p92)**:独立一套,含柱头/当心间补间/次间补间/转角
四型的正侧面全套,总高尺寸链 216.5cm,栌斗宽约 52cm(≈31分,合《法式》
栌斗32分,差在读数精度)。铺数低于一层大檐(目测单昂,待精读定级)。
→ 副阶在参数表中作为独立 bracketConfig,不与一层大檐共用。

**转角构造(图版21侧面 + 图版22 p94 平面)**:45°斜缝上斜华栱/斜昂
与两正身方向并置,平面图给出十字+斜缝三向搭交关系
→ heroCorner.js 的直接蓝本;英雄节点选型定为**一层外檐转角铺作**。

## 五、对文法引擎的架构反馈

- 版20 副阶"当心间补间/次间补间"分型 → config 需增加 bay 维度
  ('dangxin'|'cijian'),而非仅 role 三分;
- 内槽铺作与外檐同层不同级(版21 内外并列可见)→ facing 维度确认必要;
- 高度方向:材+栔的叠加节奏在版21 尺寸链中直接可读,
  assemble.js 的竖向堆叠应以"足材/单材+栔"为步进单位,不用自由高度。
