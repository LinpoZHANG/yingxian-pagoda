  README + `data/facade-material-timeline.json` + 九张按**年代命名**的照片
  (1902 伊东忠太 / 1927 / 1934 / 1936 / 2017 正射 / 2021 / 2022 / 2025 / 对照表)。
  两条对本项目有直接影响、但**本轮尚未落地**的结论:
  1. 木塔不是「全裸木立面」——木构架与**夹泥墙**共同构成立面;
  2. **20 世纪 30 年代拆除了二至五层大量夹泥墙与墙内斜撑**,改装连续格扇,
     才形成今天更通透的外观。故现状态 ≠ 辽代状态,历史年代切换须按
     `liao_1056_inferred` / `survey_1933` / `post_alteration_1936` / `current_2017_plus` 四态分。
  资料包明令:`evidence_level` 为 `inferred` 的内容只能作设计假设,须在交付说明中标明;
  **不得用照片估算米制尺寸**。
  牌匾配色现整体取自其中命名日期最新的 `2025_current_exterior.JPG`(第41轮)。

- **牌匾:图上无此对象**(第34轮实查)。版2 p74 断面、版3 p75 立面、
  版17 p91 第四·五层立面、版18 p90 第一至四层平坐立面 —— 当心间一律画到
  门额与门簪(或直棂窗)为止,其上是空壁。测绘图记录木构本体,后世悬挂的
  匾额属陈设,不入图。故 PLAQUES 的尺寸**不得标 [图]**,等级见

## 附注:量图方法

pymupdf 展平矢量路径→线段集;柱=小圆实体检测(bbox 2-16pt近方含贝塞尔),
