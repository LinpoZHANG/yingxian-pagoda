## 版权处理原则

原始扫描书与 DWG **不进交付包**(受版权保护,引用而非分发);
reference/ 目录仅存开发用关键图版截取,交付打包时排除(.gitignore 已配置)。
src/data 中每个数值标注 [测]=B组锚点 / [图]=A组量图 / [法]=营造法式 / [估]=估算,
其中 [测][图] 均须可追溯至本文件的具体图版/文件号。

**9. 维基百科·应县木塔条目**:台基分层尺寸独立印证(上层八角径35.47m等)、
历史事件时间轴;通行数据"斗拱54种480朵"采信此口径(多源一致)。

**10. 外部投稿参照**(用户提供,他人比赛作品三张):仅作叙事结构与
内容模块的参照,不取数、不复用其视觉资产;其"240组"斗拱计数与通行
"480朵"不符,不采信。
